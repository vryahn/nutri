Data integrity

Accuracy wins every trade-off

Everything is stored per 100 g and computed in SQL views at read time — values are never copied between tables. Doubtful data gets flagged ⚠, never saved silently.

Declared kcal are checked against Atwater factors (4/4/9, fiber at 2 kcal/g): a gap over 25% demands review before saving.

AI with guardrails

A fallback cascade, gated by evals

Photo label transcription runs on free-tier keys. Any error — timeout, quota, invalid JSON — falls through to the next model without the user noticing.

A scored golden set of real label photos runs before every AI change: any regression against baseline blocks the push.

gemini-3.5-flash ✗ timeout → gemini-2.5-flash ✗ 429 → mistral-small ✓
✓ npm run eval — regression vs baseline = no deploy

The Gemini schema is translated to strict JSON Schema for Mistral — same structured output, different dialect.

Search

Semantic search over the catalog

Hybrid retrieval: exact match answers first; if it comes up short, pgvector completes with cosine similarity over 768-dim embeddings generated when each food is saved.

The same infrastructure powers 'Ask your log': a 3-step RAG pipeline that answers questions citing only real logged data.

Security

Privacy by design

Row Level Security isolates every user inside Postgres: the filter lives in the database, not in the UI. No secret key ships to the client.

The repo is public with zero credentials in its history — the design assumes the code can be read by anyone.

create policy foods_select
  on nutri.foods for select
  using (owner = auth.uid());
session: user A Greek yogurt Oats Café de olla
user B's rows ████████████ ██████████ █████████████

Postgres doesn't even return the other user's rows — it's not a UI filter a bug could skip.

Interoperability

Its own MCP connector

A remote MCP server with OAuth exposes 8 tools — log, search, audit — acting with each user's own identity, under the same RLS.

The food log became conversational: logging a meal or auditing a week happens from any MCP client — Claude, ChatGPT, Perplexity and more — no UI needed.

Log 150 g of Greek yogurt and 30 g of granola
Done — 265 kcal, 18 g protein added to today.
How's my sodium this week?
Averaging 1,870 mg/day. Monday landed at 1,320 mg ⚠ — under the 1,500 floor.

Real interaction pattern with the production connector — the open MCP standard makes it work with any compatible client.

Design system

A palette that never lies

The accent never occupies a data hue — carbs live in indigo so 'primary button' and 'protein' can't mean the same color.

Each theme recalculates lightness in OKLCH against its worst background: every text/background pair stays at or above 4.5:1.
